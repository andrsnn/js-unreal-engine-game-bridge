# Generated sound effects

80 original game sound effects generated locally on September 11, 2026 with
Stability AI Stable Audio 3 Small SFX (433M), using eight inference steps.

Model and runtime: https://github.com/Stability-AI/stable-audio-3
Prompt guidance: https://stability.ai/guides/stable-audio-3-prompt-guide

Prompts describe original weapons, machinery, creatures and interactions. No
recordings or soundtracks from The Expanse or other entertainment were supplied.
Generation settings, seeds and source descriptions: tools/generate-game-sfx.py
and reports/stable-audio-3/generated.json in the source repository.

Edited for game playback: onset trimming, gain balancing, short tail fades,
crossfaded engine/beam loops, and Ogg Vorbis encoding. The model's own applicable
license governs the model; this file does not relicense it or the legacy assets.
